# Village prototype

Throwaway look-and-feel test for The Blacksmith: Phaser 3 village, walking NPCs, mocked smith dialogue, witnesses, and gossip with decaying confidence. No model calls; all dialogue is canned.

```bash
npm install
npm run dev
```

Open http://localhost:5173. Move with WASD/arrows, press E next to someone to talk, Esc to leave. Use "+1 hour" to skip time to delivery.

Tile reference pages: `/debug/town.html`, `/debug/dungeon.html`.
