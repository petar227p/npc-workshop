# Branding

The home page uses the full gold pixel logo. The workshop and demo headers use the N-in-a-gear icon beside the product name.

Assets live in `web/public/brand/`:

| File | Use |
|---|---|
| `npc-workshop-logo.png` | 600 × 336 transparent logo |
| `npc-workshop-icon.png` | 512 × 512 transparent icon |
| `favicon-16/32/48.png`, `../favicon.ico` | Favicons (the `.ico` holds all three sizes) |
| `apple-touch-icon.png` | 180 px Apple touch icon |
| `roles/*.png` | Role emblems shown in the Workshop |

Keep the shaded pixel style and proportions when making new versions.
