# NPC role logos

Eleven transparent PNG role emblems generated with the built-in imagegen tool, using the approved NPC Workshop icon and wordmark as style references. Each retains a gold pixel gear and charcoal center with an individual role symbol. Original brand assets are unchanged.

[Open the visual gallery](gallery.html). Production assets are in [web/public/brand/roles](../../../web/public/brand/roles). The complete prompt set and role mapping are in [prompts.json](prompts.json).

Merchant and guard cover both workshop templates and village jobs. Craftsperson and blacksmith have distinct symbols; villager has a general cottage mark. Storyteller has a general book mark plus separate bard and town crier variants.
